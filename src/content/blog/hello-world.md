## Writing a post

Each post is a Markdown (`.md`) or MDX (`.mdx`) file with frontmatter:

```md
---
title: 'post title'
description: 'one-line summary shown in the blog list.'
date: '2026-10-22T12:00:00-07:00'
tags: ['notes']
categories: ['engineering']
draft: false
---
```

Set `draft: true` to keep a post out of the published site.
